# Employee Wellness Management Analytics – Milestone 1

## User Authentication Module

### Project Objective
Develop a secure user authentication system for the Employee Wellness Management Analytics application. The module enables user registration, email verification using OTP, secure login, password reset, and session management.

---

## Technologies Used
- Python
- Streamlit
- PostgreSQL (Neon Database)
- JWT (JSON Web Token)
- Google SMTP (Gmail App Password)
- bcrypt (Password Hashing)
- email-validator
- Google Colab

---

## Features
- User Registration
- Email OTP Verification
- Secure Login
- Forgot Password with OTP
- Password Reset
- JWT-based Session Management
- Secure Password Hashing
- PostgreSQL Database Integration
